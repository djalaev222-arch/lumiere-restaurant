# Деплой на Render (бесплатно)

Репозиторий уже содержит `render.yaml` — Render прочитает его и сам создаст все три сервиса. От вас нужны только клики в браузере — я не могу завести аккаунт на хостинге за вас.

## Шаги

1. Зайдите на **[render.com](https://render.com)** и зарегистрируйтесь — проще всего через "Sign up with GitHub" (тот же аккаунт, куда запушен репозиторий).
2. В дашборде: **New +** → **Blueprint**.
3. Выберите репозиторий `lumiere-restaurant`. Render найдёт `render.yaml` и покажет превью: два веб-сервиса (`lumiere-api`, `lumiere-site`) и одну базу (`lumiere-db`).
4. Нажмите **Apply**. Первый деплой займёт несколько минут — Render поставит зависимости, применит миграции и засеет меню.
5. Когда сервисы позеленеют, сайт будет доступен по адресу вида `https://lumiere-site.onrender.com` (Render может подставить другое имя, если это занято — тогда ссылка будет отличаться, посмотрите её в дашборде у сервиса `lumiere-site`).

## Вход в админку

Пароль администратора Render генерирует сам (это безопаснее, чем дефолтный `change-me-now` в коде). Найти его:

**lumiere-api** → вкладка **Environment** → переменная `ADMIN_PASSWORD`.

Логин: `admin@lumiere-restaurant.ru`.

## На что обратить внимание (бесплатный тариф)

- **Сервис "засыпает"** после 15 минут без запросов и просыпается ~30–50 секунд на первый заход после паузы — это ограничение бесплатного плана Render, не баг.
- **Бесплатная база** у Render ограничена по времени жизни — проверьте актуальные условия в их тарифах, если планируете держать сайт долго; для реального проекта потом можно перейти на платный план без потери данных.
- Оплата (ЮKassa), e-mail и Telegram-уведомления по умолчанию **не настроены** — сайт работает в демо-режиме (как и локально). Чтобы включить: впишите переменные (`YOOKASSA_SHOP_ID`, `SMTP_HOST`, `TELEGRAM_BOT_TOKEN` и т.д. — полный список в `server/.env.example`) в **lumiere-api → Environment** и передеплойте сервис.
- Если поменяете имя сервиса `lumiere-site` при импорте блюпринта, обновите `CORS_ORIGIN` в `lumiere-api` и `VITE_API_URL` в `lumiere-site` на реальные адреса — иначе фронтенд не сможет достучаться до API из-за CORS.

## Локальная разработка не меняется

`render.yaml` использует отдельную PostgreSQL-схему (`server/prisma/production/`) только для деплоя. Ваш `npm run dev` и тесты (`npm test`, `npm run test:e2e`) как и раньше работают на SQLite без каких-либо дополнительных шагов.
